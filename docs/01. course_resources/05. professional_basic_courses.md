## 计算机技术基础（双语）

### 考试信息

1. 要求全英语作答，闭卷；
2. 考试题目类型每年不太一样，但是一定会考课后题；
3. 想得高分就背会所有课后题，包括连线题，选择题，主观问答题；
4. 每章章末有本章总结，要想满绩则需要全背。
